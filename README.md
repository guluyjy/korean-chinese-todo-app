# 한중 양식 할 일 관리 앱 / 韩中双语待办管理工具

## 📌 作品用途
간단한 할 일을 기록하고 관리하는 웹 앱입니다. 모든 UI 텍스트는 한국어·중국어 병기되어 있습니다.
一款记录、管理待办事项的网页应用，全部界面文字韩中双语对照。

## ✨ 主要功能
- 할 일 추가 / 添加待办
- 체크박스로 완료 상태 표시 / 勾选标记完成
- 개별 할 일 삭제 / 单独删除任务
- 전체 목록 초기화 / 一键清空全部
- 弹窗、按钮、提示文字中韩双语

## ▶ 运行方法
1. 下载 index.html 文件
2. 使用浏览器直接打开文件
3. 在输入框填写内容即可使用
